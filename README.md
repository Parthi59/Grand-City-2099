# Grand City 2099

An original open-world city game featuring driving, bikes, traffic, pedestrians, combat, garages, missions, dynamic audio, horn controls and gamepad support.

## Features

- Open-world city environment
- Cars and bikes
- Realistic vehicle controls
- Horn system
- Gamepad/controller support
- Traffic and pedestrians
- Combat system
- Garages
- Missions and contracts
- Dynamic city audio
- Police sirens
- Vehicle engine and braking sounds
- Keyboard and touch controls

## Controls

### Keyboard
- WASD / Arrow Keys — Move / Drive
- Shift — Sprint / Nitro
- Space — Handbrake
- H — Horn
- E — Enter / Exit Vehicle
- C — Camera
- G — Garage
- M — Contracts
- P / Esc — Pause
- 1 / 2 — Weapons
- R — Reload

### Gamepad
- Left Stick — Movement / Steering
- RT — Accelerate
- LT — Brake / Reverse
- RB — Nitro
- B — Handbrake
- X — Horn
- A — Enter / Exit Vehicle
- Y — Camera
- Start — Pause
